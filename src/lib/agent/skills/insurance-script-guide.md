# Insurance Knowledge Video Script Guide

## Script structure for 60-90 second videos

### Hook (0-5s)
- Start with a question or surprising stat
- Example: "你知道90%的人买错了保险吗？"
- Example: "重疾险和百万医疗险，到底该买哪个？"

### Body (5-60s)
- Explain one concept clearly
- Use simple language, avoid jargon
- Include 1-2 specific examples or numbers
- Structure: Problem → Solution → Why it matters

### Call to Action (60-75s)
- Tell viewer what to do next
- Example: "关注我，每天分享一条保险干货"
- Example: "评论区告诉我你的情况，我帮你分析"

### Outro (75-90s)
- Brand identity
- Contact info (微信/公众号)

## Voice tone guidelines
- **Friendly (亲切)**: Like chatting with a friend, use "你" and everyday language
- **Professional (专业)**: Accurate terminology, logical flow, cite regulations
- **Simple (简单)**: Use metaphors, avoid numbers-heavy content, one concept per video
- **Authoritative (权威)**: Reference specific policies, laws, and statistics

- 重疾险 vs 百万医疗险的区别
- 定期寿险该买多少保额
- 儿童保险怎么选
